HTML METHODS & TAGS DOCUMENTATION

1. FORM METHOD ATTRIBUTE

The method attribute specifies how form data is sent to the server. It has two main values: GET and POST.

GET Method

Appends form data to the URL as name/value pairs. Used for non-sensitive data like search queries. Data is visible in the address bar. 

<form action="/search" method="GET">
    <input type="text" name="query">
    <button type="submit">Search</button>
</form>

POST Method

Sends form data in the request body. Used for sensitive data like passwords, logins, or file uploads. Data is not visible in the address bar and has no size limit. 

<form action="/login" method="POST">
    <input type="text" name="username">
    <input type="password" name="password">
    <button type="submit">Login</button>
</form>
Method Data Location Visible in URL Security
GET Query string Yes Low
POST Request body No High

2. TEXT FORMATTING TAGS

<p> - Paragraph

Defines a paragraph of text. Block-level element.

<p>This is a paragraph.</p>

<br> - Line Break

Inserts a single line break. Void element (no closing tag).

Line one<br>Line two

<b> vs <strong>

<b> makes text bold (visual only).
<strong> indicates important text (semantic). 

<b>Bold text</b>
<strong>Important text</strong>

<i> vs <em>

<i> makes text italic (visual only).
<em> emphasizes text (semantic). 

<i>Italic text</i>
<em>Emphasized text</em>

<u> - Underline

Underlines the text.

<u>Underlined text</u>

<s> - Strikethrough

Shows text with a line through it.

<s>Struck text</s>

<sup> & <sub>

<sup> - Superscript: x2
<sub> - Subscript: H2O 

(a+b)<sup>2</sup>
H<sub>2</sub>O

<pre> - Preformatted Text

Preserves spaces, tabs, and line breaks exactly as typed.

<pre>
This    text
keeps   spacing
</pre>

3. ANCHOR TAG ATTRIBUTES

href

Specifies the destination URL.

<a href="https://example.com">Visit Site</a>

target

Value Behavior
_blank Opens in a new tab/window
_self Opens in same frame (default)
_parent Opens in parent frame
_top Opens in full body of window 
<a href="page.html" target="_blank">New tab</a>

title

Shows a tooltip when hovering over the link.

<a href="page.html" title="Go to page">Hover me</a>

4. MEDIA TAGS

<img>

Embeds an image. Uses src for source and alt for fallback text.

<img src="images/photo.jpg" alt="My Photo" height="300">

<video>

Embeds a video with playback controls.

<video height="300" controls loop muted>
    <source src="assets/video.mp4" type="video/mp4">
    Browser does not support video.
</video>

5. SEMANTIC LAYOUT TAGS

Tag Purpose
<header> Introductory content / site title
<nav> Navigation links container
<main> Dominant content (only one per page)
<section> Standalone section with a heading
<article> Self-contained reusable content
<aside> Indirectly related content / sidebar
<footer> Footer for author info, copyright
