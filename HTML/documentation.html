1. DOCUMENT STRUCTURE & DOCTYPE

Every HTML document starts with a doctype declaration which tells the browser which version of HTML is being used. The HTML5 doctype is: 

<!DOCTYPE html>

The basic skeleton of an HTML page:

<!DOCTYPE html>
<html lang="en">
    <head>
        <meta charset="UTF-8">
        <title>Page Title</title>
    </head>
    <body>
        Content goes here
    </body>
</html>
Tag Description
<!DOCTYPE html> Declares HTML5 version
<html> Root element of the page; lang attribute sets language
<head> Contains metadata, not visible to users
<body> Contains all visible content

<html> is a container for all other HTML elements. The lang attribute (e.g. lang="en") declares the document language for accessibility and search engines.

2. HEAD & METADATA TAGS

The <head> element contains information about the document. It is never displayed.

<meta>

Provides metadata about the page. Common uses:

<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="description" content="Page description for SEO">
<meta name="keywords" content="html, css, web">
<meta name="author" content="Ayush Nandi">
Attribute Purpose
charset Character encoding (usually UTF-8)
name="viewport" Controls layout on mobile devices
name="description" Shown in search engine results
name="keywords" Relevant search keywords
name="author" Page author name

<title>

Defines the tab title shown in the browser.

<title>My Website</title>

<link>

Links external resources like CSS stylesheets.

<link rel="stylesheet" href="style.css">

<base>

Sets a base URL for all relative links in the document.

<base href="https://example.com/">

3. TEXT & FORMATTING TAGS

Heading Tags (h1 - h6)

Define headings. h1 is the largest/most important, h6 the smallest.

<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>

Result:

Heading 1

Heading 2

Heading 3

Heading 4

Heading 5

Paragraph & Line Breaks

<p>This is a paragraph.</p>
<br> <!-- line break -->
<hr> <!-- horizontal rule -->

<p> defines a paragraph. <br> inserts a line break (void tag). <hr> draws a horizontal line to separate content.

4. LINKS, IMAGES & MEDIA

<a> - Anchor (Hyperlink)

The anchor tag creates hyperlinks.

<a href="https://example.com" target="_blank" title="Tooltip">Link Text</a>
Attribute Description
href Destination URL or #id for internal links
target Where to open: _blank, _self, _parent, _top
title Tooltip shown on hover
  • _blank - new tab/window
  • _self - same frame (default)
  • _parent - parent frame
  • _top - full body of window

Internal jump links use #id:

<a href="#contact">Go to Contact</a>

<section id="contact">...</section>

<img> - Image

Embeds an image. It is a void element (self-closing).

<img src="images/photo.jpg" alt="Description" width="300" height="200">
Attribute Description
src Image file path or Base64 data URI
alt Fallback text (accessibility & if image fails)
width / height Display dimensions (px)
title Tooltip on hover

<video> - Video

<video width="400" controls autoplay loop muted>
    <source src="assets/video.mp4" type="video/mp4">
    Your browser does not support video.
</video>
Attribute Description
controls Show play/pause controls
autoplay Auto starts playing
loop Repeats video
muted Starts muted
poster Preview image before play

<audio> - Audio

<audio controls>
    <source src="audio/song.mp3" type="audio/mpeg">
    Browser does not support audio.
</audio>

5. LISTS

Unordered List (<ul>)

Bullet-point list. Each item uses <li>.

<ul>
    <li>Apple</li>
    <li>Banana</li>
</ul>
  • Apple
  • Banana

Ordered List (<ol>)

Numbered list. Use the type attribute to change numbering style.

<ol>
    <li>First</li>
    <li>Second</li>
</ol>
  1. First
  2. Second
Type Value Style
1 Numbers (default)
A Uppercase letters
a Lowercase letters
I Uppercase roman numerals
i Lowercase roman numerals 
<ol type="A">...</ol>

Description List (<dl>)

Pairs a term (<dt>) with a description (<dd>).

<dl>
    <dt>HTML</dt>
    <dd>HyperText Markup Language</dd>
</dl>
HTML
HyperText Markup Language

Nested Lists

<ul>
    <li>Fruits
        <ul>
            <li>Apple</li>
            <li>Mango</li>
        </ul>
    </li>
</ul>

6. TABLES

Tables organize data into rows and columns.

<table border="1" cellpadding="5">
    <thead>
        <tr>
            <th>Name</th>
            <th>Age</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Ayush</td>
            <td>20</td>
        </tr>
    </tbody>
</table>
Name Age
Ayush 20
Tag Role
<table> Table container
<tr> Table row
<th> Header cell (bold, centered)
<td> Data cell
<thead> Header group
<tbody> Body group
<tfoot> Footer group
<caption> Table title

Merge cells using colspan (horizontal) and rowspan (vertical):

<td colspan="2">Spans two columns</td>
<td rowspan="2">Spans two rows</td>

7. FORMS & INPUT METHODS

The <form> tag collects user input. The method attribute determines how data is submitted. 

<form action="/submit" method="POST">
    ...
</form>

Method Attribute

Method Data Location Visible in URL Best For
GET Query string Yes Searches, filters, bookmarks
POST Request body No Logins, uploads, sensitive data

<input> Types

<input type="text" name="username" placeholder="Enter name">
<input type="password" name="pass">
<input type="email" name="email">
<input type="number" name="age" min="1" max="100">
<input type="date" name="dob">
<input type="checkbox" name="agree">
<input type="radio" name="gender" value="male">
<input type="file" name="avatar">
<input type="color" name="color">
<input type="range" name="vol" min="0" max="100">
<input type="submit" value="Send">
<input type="reset" value="Clear">
Type Purpose
text Single-line text input
password Masked text (dots)
email Validates email format
number Numeric input with min/max
date Date picker
checkbox Multi-select toggle
radio Single-select from group
file File upload
color Color picker
range Slider control
submit Submit button
reset Clears the form

<button>

<button type="submit">Submit</button>
<button type="reset">Reset</button>
<button type="button" onclick="alert('Hi')">Click Me</button>

<select> & <option>

Dropdown menu.

<select name="country">
    <option value="india">India</option>
    <option value="usa">USA</option>
</select>

<textarea>

Multi-line text input.

<textarea name="message" rows="4" cols="30">Default text</textarea>

<label>

Associates a text label with a form control using the for attribute.

<label for="name">Name:</label>
<input type="text" id="name" name="name">

<fieldset> & <legend>

Groups related form fields with a title.

<fieldset>
    <legend>Personal Info</legend>
    ...
</fieldset>

Form Attributes

Attribute Description
action URL where data is sent
method GET or POST
name Form name for scripting
autocomplete on/off browser autofill
enctype Encoding (needed for file upload)
target Where to open the response

8. SEMANTIC LAYOUT TAGS

Semantic tags describe the meaning of content, improving accessibility and SEO.

Tag Purpose
<header> Introductory content / site title at top
<nav> Navigation links container
<main> Primary content (only one per page)
<section> Thematic grouping with a heading
<article> Self-contained, reusable content
<aside> Sidebar / indirectly related content
<footer> Footer: author, copyright, links
<figure> Self-contained media with caption
<figcaption> Caption for a <figure>
<details> Collapsible content
<summary> Visible heading of <details> 
<header>
    <h1>Site Title</h1>
</header>

<nav>
    <a href="#home">Home</a> |
    <a href="#about">About</a>
</nav>

<main>
    <section id="home">
        <h2>Home</h2>
        <article>
            <h3>Article Title</h3>
            <p>Article content.</p>
        </article>
    </section>
</main>

<footer>
    <p>&copy; 2026 AYUSH NANDI</p>
</footer>

Generic Containers

<div> is a generic block-level container, and <span> is a generic inline container. Both are used with CSS classes/id. 

<div class="box">Block content</div>
<p>Text with a <span class="highlight">highlighted</span> word.</p>

9. IFRAMES & EMBEDDING

<iframe>

Embeds another HTML document inside the current page.

<iframe src="page.html" width="600" height="400">
    Fallback text
</iframe>
Attribute Description
src URL of the embedded page
width / height Frame dimensions
frameborder Show/hide border
loading lazy / eager loading

11. HTML COMMENTS

Comments are notes in the code that are not displayed in the browser.

<!-- This is a single-line comment -->

<!--
    This is a
    multi-line comment
-->

Comments are useful for explaining sections of code to other developers.
